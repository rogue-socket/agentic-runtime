**Changelog**

This folder collects dated change notes for the codebase and documentation.

**Format**

Each entry should include:
- date
- summary
- key changes grouped by area (runtime, CLI, docs, tests)
- migration notes if behavior changed

**Entries**

- `docs/changelog/CHANGELOG_2026-03-19.md`
- `docs/changelog/CHANGELOG_2026-03-18.md`
- `docs/changelog/CHANGELOG_2026-03-17.md`
- `docs/changelog/CHANGELOG_2026-03-16.md`
