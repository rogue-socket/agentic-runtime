# Reference Project

This folder contains the bundled runnable sample project content for the framework repository.

It mirrors the structure produced by `ai init` / `ai quickstart`:

- `agents/`
- `functions/`
- `prompts/`
- `tools/`
- `workflows/`

Purpose:

- Keep the repository root focused on framework code (`src/agent_runtime/`)
- Preserve realistic end-to-end examples used by docs and tests
- Provide contributors with a concrete, runnable reference project
